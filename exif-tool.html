// Batch processing

Process a whole folder in one click.

Whether you're sharing a single hero shot or exporting an entire session, the batch engine handles it.

Apply to all — configure your overlay once and point it at a folder; every photo gets the same treatment in one click
Per-image settings — step through each image and dial in exactly what each shot needs: fields, position, colour and size
Unlimited photos — no cap on folder size; the tool runs through every image without slowing down
Always non-destructive — originals stay untouched; each stamped file is written as a fresh _exif copy

First Launch — macOS Security

macOS Gatekeeper blocks unsigned apps on first launch. Use any one of these methods to allow it — after that, it opens normally every time.

Method 1 Right-click to Open Recommended
  1. Double-click the ZIP to extract it
  2. Right-click EXIF Overlay Tool.app → Open
  3. Click Open on the security dialog
  4. From second launch onwards, double-click opens normally
Method 2 System Settings Easiest
  1. Try to open the app — macOS will block it
  2. Go to System Settings → Privacy & Security
  3. Scroll down — you’ll see “EXIF Overlay Tool was blocked”
  4. Click Open Anyway → enter your Mac password → opens
Method 3 Terminal Most reliable

Run this command once in Terminal, replacing the path with where you saved the app:

xattr -cr "/path/to/EXIF Overlay Tool.app"

After running this command, the app opens normally on double-click — no security dialog.

Apple has not verified this app. Right-click → Open bypasses Gatekeeper safely. For company-managed Macs, contact your IT administrator.

Now inside Lightroom Classic.

Stamp EXIF overlays without leaving Lightroom Classic — straight from the Plug-in Extras menu.

  1. Download the .lrplugin zip and extract it.
  2. Open Lightroom Classic.
  3. Go to File → Plug-in Manager.
  4. Click Add (bottom-left).
  5. Select the extracted .lrplugin folder.
  6. Click Done.
  7. Find it under File → Plug-in Extras.
